# 📈 Detaillierte Analyse: Repowering-Potenzial in Thüringen

## 1. Nordthüringen
- **Repowering-Potenzial**: 59.3 MW
- **Standorte**: Eichsfeld, Mühlhausen, Dingelstädt
- **Laufende Projekte**:
  - Windpark Höheberg (27 MW, In Bau)
  - Windpark Hainich (50 MW, Genehmigt)

## 2. Mittelthüringen
- **Repowering-Potenzial**: 51.1 MW
- **Standorte**: Erfurt, Gotha, Weimar
- **Herausforderungen**: Bürgerproteste, Flächenknappheit

## 3. Ostthüringen
- **Repowering-Potenzial**: 13.15 MW
- **Standorte**: Gera, Altenburg, Schmölln
- **Herausforderungen**: Naturschutz, Bodenbelastung

## 4. Südthüringen
- **Repowering-Potenzial**: 25.9 MW
- **Standorte**: Schmalkalden-Meiningen, Suhl, Eisenach
- **Herausforderungen**: Naturschutz, Tourismus
